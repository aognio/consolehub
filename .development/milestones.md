# Project Milestones

- [ ] **Milestone 1**: Foundation & Scaffolding (Config TOML loader, PocketBase embedded boot, schema migrations).
- [ ] **Milestone 2**: Authentication & Tenancy (Session auth engine, cookie secret handling, RBAC, tenant context middleware).
- [ ] **Milestone 3**: Ingestion Transport (JSON-RPC 2.0 over WebSocket adapter, REST fallback, sequence deduplication).
- [ ] **Milestone 4**: Stream PubSub Hub (In-memory fanout, SSE broadcaster for web UI).
- [ ] **Milestone 5**: UI Framework & Pages (Light/Dark mode layout, Dashboard, Tenants, Hosts, Apps, Runs, Search views).
- [ ] **Milestone 6**: Flagship Console Viewer (Real-time terminal view, auto-scroll, tail mode, pause/resume, JSON rendering).
- [ ] **Milestone 7**: Integration Verification & Documentation Suite.
